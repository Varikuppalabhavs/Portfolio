# Bhavani's Portfolio

A small portfolio website showcasing my skills, projects, and education.

## ⚡ Features

* 🌸 **Pastel Design** Soft pink and lavender palette with Fraunces + Sora typography
* 🖱️ **Interactive Hero** Mouse-reactive floating blobs and a live scroll cue
* 🧭 **Scroll-Aware Navigation** Nav links highlight automatically as you scroll, with a responsive mobile menu
* 🎯 **Expandable Project Cards** Tap a project to reveal details, tech stack, and live links
* 🏷️ **Animated Skill Pills** Hover effects across languages, web dev, CS fundamentals, and tools
* 📜 **Education Timeline** A clean vertical timeline of academic history
* 🎓 **Linked Certifications** Every certificate card links to its real verification page
* ✉️ **One-Tap Contact** Copy-to-clipboard email plus direct LinkedIn, GitHub, and phone links

## 🛠️ Built With

HTML, CSS, and vanilla JavaScript — no frameworks, no build step, deploys instantly anywhere.
